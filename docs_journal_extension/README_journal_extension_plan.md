# CRISPR-MDR Journal Extension Plan

This folder tracks the journal-extension modules built after the BIBM-ready FOTR-CRISPR core.

Planned modules:
1. Full MIT/CFD/Cas-OFFinder/CRISOT comparison table
2. External bacterial genome validation
3. Genome-wide functional off-target annotation
4. Negative controls
5. Prospective unseen AMR genes
6. Evolutionary escape simulation
7. Pareto-front ranking
8. Clinical-priority layer
9. Interactive CLI/dashboard
10. Multiplex guide-set design

The BIBM core remains focused on FOTR-CRISPR single-guide prioritization, RNA accessibility, CRISOT spacer-level comparison, functional context, ablation, and mecA case study.
